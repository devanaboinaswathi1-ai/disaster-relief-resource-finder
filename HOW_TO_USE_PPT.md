## 🔧 Troubleshooting

### Problem: File Won't Open
**Solution:**
- Ensure Microsoft PowerPoint is installed
- Try opening with Google Slides (upload to Drive)
- Use LibreOffice Impress (free alternative)

### Problem: Fonts Look Different
**Solution:**
- PowerPoint may substitute fonts if not available
- Go to "File" → "Options" → "Save"
- Check "Embed fonts in the file"
- Save again

### Problem: Slides Look Distorted on Projector
**Solution:**
- Check projector resolution settings
- Use "Slide Show" → "Set Up Show"
- Select appropriate resolution
- Test before presentation

### Problem: Can't Edit Text
**Solution:**
- Click directly on the text box
- If still locked, right-click → "Edit Text"
- Ensure you're not in Slide Show mode

## 🎤 Preparing for Q&A

### Common Questions & Answers

**Q1: Why did you choose PHP over Node.js or Python?**
A: PHP is widely supported on shared hosting, easy to deploy with XAMPP, and has excellent MySQL integration. It's also the most common server-side language for web applications.

**Q2: How accurate is the distance calculation?**
A: We use the Haversine formula which calculates great-circle distances between two points on a sphere. It's accurate within a few meters for distances up to 100 km.

**Q3: How do you ensure data security?**
A: We use prepared statements to prevent SQL injection, session management for admin authentication, and HTTPS can be enabled for production deployment.

**Q4: Can this scale to handle many users?**
A: Yes, the architecture supports horizontal scaling. We can add load balancers, database replication, and CDN for map tiles to handle thousands of concurrent users.

**Q5: How do you keep the data updated?**
A: Administrators can update relief center information in real-time through the admin dashboard. Future enhancements include crowdsourced updates with verification.

**Q6: What happens if internet is not available?**
A: Currently, internet is required for map tiles. Future enhancement includes service workers for offline mode, caching map tiles and center data locally.
